El catálogo de algoritmos reúne 10 problemas de programación comunes y 10 patrones algorítmicos reutilizables. Cada solución es una implementación en TypeScript respaldada por pruebas automatizadas, así que el código de cada página es el mismo que pasa esas pruebas.

Usa el catálogo para estudiar una técnica, prepararte para entrevistas de programación o encontrar una implementación de referencia para un problema conocido.

La complejidad usa la notación Big O. Por ejemplo, `O(n)` significa que el costo crece de forma lineal con el tamaño de la entrada `n`. Para aprender a interpretar estos valores, consulta [Análisis de complejidad](/es/algorithms/patterns/complexity-analysis).
