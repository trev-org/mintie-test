Visita cada nodo mediante un recorrido recursivo o iterativo en profundidad o en anchura.

## Cuándo usarlo

- Transformar un árbol.
- Agregar resultados de subárboles.
- Buscar en datos jerárquicos.

## Pasos

1. Define el caso base del árbol vacío.
2. Procesa el nodo actual.
3. Recorre los subárboles hijos.

## Complejidad

| Medida | Costo típico |
| --- | --- |
| Tiempo | `O(n)` |
| Espacio | `O(h)` |

## Problemas de ejemplo

- [Invert Binary Tree](/es/algorithms/problems/invert-binary-tree): refleja un árbol binario intercambiando los hijos izquierdo y derecho de cada nodo.
