## About this reference

This dropdown documents Kraken's maintained Spot WebSocket v1 API. The generated reference includes the live public server, connection-management messages, ping and pong payloads, and public market-data subscriptions.

## Sources

- [Official Kraken Spot WebSocket documentation](https://docs.kraken.com/exchange/api-reference/spot-websocket)
- [Official Kraken WebSocket introduction](https://docs.kraken.com/exchange/guides/websockets/introduction)

<Note>
  The AsyncAPI document is maintained locally because Kraken does not publish an official AsyncAPI artifact. It targets the production endpoint at `wss://ws.kraken.com`.
</Note>
