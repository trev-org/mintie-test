## About this reference

This reference covers two APIs included in OpenWeather's free subscription:

- Current weather conditions for geographic coordinates
- Five-day forecasts in three-hour intervals

Mintlify generates the endpoint pages and interactive request playground from the local OpenAPI document at `reference/openweather-free.yaml`.

## Before you begin

1. Sign in to these docs.
2. Open any endpoint in this reference.
3. Use the authenticated playground with the prefilled `appid` value.

The documentation authentication service supplies the OpenWeather key assigned
to your `partner` or `enterprise` group after sign-in. Users in both groups
receive the enterprise key. The keys are not stored in this repository.

<Note>
  These endpoints do not require the separate One Call by Call subscription.
  OpenWeather's free-plan request limits still apply.
</Note>

<Warning>
  The key is visible to authenticated users in their browser. Do not reuse it
  for privileged workloads, and configure an appropriate OpenWeather request
  quota.
</Warning>
