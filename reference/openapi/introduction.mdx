## About this reference

This reference covers all six OpenWeather One Call API 4.0 endpoints:

- Current weather
- 1-minute, 15-minute, hourly, and daily timelines
- Detailed weather alerts

Mintlify generates the endpoint pages and interactive request playground from the local OpenAPI document at `reference/openweather-one-call-4.yaml`.

## Before you begin

1. Sign in to these docs.
2. Open any endpoint in this reference.
3. Use the authenticated playground with the prefilled `appid` value.

The documentation authentication service supplies the OpenWeather key after
sign-in. The key is not stored in this repository.

<Note>
  OpenWeather includes a daily free allowance with the One Call by Call subscription. Check its current pricing and limits before sending production traffic.
</Note>

<Warning>
  The key is visible to authenticated users in their browser. Do not reuse it
  for privileged workloads, and configure an appropriate OpenWeather request
  quota.
</Warning>
