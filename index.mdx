## A useful learning loop

<Steps>
  <Step title="Recognize the shape">
    Identify the input, constraints, and repeated work before choosing a data
    structure or algorithm.
  </Step>
  <Step title="State the algorithm">
    Write the steps in plain language and identify the invariant that remains
    true while the implementation runs.
  </Step>
  <Step title="Implement and test">
    Compare your solution with the tested TypeScript implementation, including
    its edge cases.
  </Step>
  <Step title="Analyze complexity">
    Explain how runtime and auxiliary memory grow with the input.
  </Step>
</Steps>
