Use it as a tour: click through the tabs and pages below, then open the source repos to see how each piece is wired up.

## How to tour the site

<Steps>
  <Step title="Read the product narrative">
    Start at [Introduction](/introduction), then skim
    [Concepts](/concepts/how-sso-works) and [Setup](/setup/enable-sso) for
    component-heavy guides.
  </Step>
  <Step title="Open the References tab">
    Switch to **References** in the top nav for OpenAPI, AsyncAPI, GraphQL, and
    the TypeScript SDK — each generated from a spec file in this repo.
  </Step>
  <Step title="Check the Changelog tab">
    See tagged release notes on [Changelog](/changelog/overview).
  </Step>
  <Step title="Fork the source">
    Clone [`mintie-test`](https://github.com/trev-org/mintie-test) (docs) and
    [`mintie-test-code`](https://github.com/trev-org/mintie-test-code) (app
    code), then run `mint dev` locally to iterate.
  </Step>
</Steps>

<Tip>
  Prefer the Mintlify docs over this sample when you need canonical guidance:
  [Components](https://www.mintlify.com/docs/components), [API
  playground](https://www.mintlify.com/docs/api-playground/overview), and
  [docs.json](https://www.mintlify.com/docs.json).
</Tip>
