## Recommended operating rhythm

| Cadence | Task |
| --- | --- |
| Before launch | Complete the readiness checklist and run a pilot |
| Weekly | Run a test sign-in and review provider-side failures |
| Monthly | Confirm admin ownership and recovery contacts |
| Quarterly | Review credentials, assignments, and unused accounts |
| After any IdP change | Re-test sign-in and one complete user lifecycle |

<Info>
  SCIM, the audit-log dashboard, and parts of session migration are still in
  development. The runbooks identify checks that depend on those features.
</Info>
