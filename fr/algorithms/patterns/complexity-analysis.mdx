Décrivez comment le temps d'exécution et la mémoire auxiliaire augmentent avec la taille de l'entrée.

## Quand l'utiliser

- Comparer des approches valides.
- Expliquer la scalabilité.
- Documenter les compromis.

## Étapes

1. Identifiez la taille de l'entrée.
2. Comptez les opérations dominantes.
3. Supprimez les constantes et les termes d'ordre inférieur.

## Complexité

| Mesure | Coût typique |
| --- | --- |
| Temps | Variable selon l’algorithme |
| Espace | Variable selon l’algorithme |

## Exemples de problèmes

- [Two Sum](/fr/algorithms/problems/two-sum) : renvoyez les index de deux nombres dont la somme est égale à la cible.
- [Valid Parentheses](/fr/algorithms/problems/valid-parentheses) : déterminez si chaque parenthèse ouvrante est fermée dans le bon ordre.
- [Valid Palindrome](/fr/algorithms/problems/valid-palindrome) : vérifiez si les caractères alphanumériques se lisent de la même façon dans les deux sens, sans tenir compte de la casse.
- [Binary Search](/fr/algorithms/problems/binary-search) : trouvez une valeur cible dans un tableau trié et renvoyez son index.
- [Merge Two Sorted Lists](/fr/algorithms/problems/merge-two-sorted-lists) : fusionnez deux listes chaînées triées en une seule liste triée en réutilisant leurs nœuds.
- [Best Time to Buy and Sell Stock](/fr/algorithms/problems/best-time-to-buy-and-sell-stock) : trouvez le plus grand profit possible avec un achat suivi d'une vente ultérieure.
- [Invert Binary Tree](/fr/algorithms/problems/invert-binary-tree) : obtenez le miroir d'un arbre binaire en échangeant les enfants gauche et droit de chaque nœud.
- [Flood Fill](/fr/algorithms/problems/flood-fill) : recolorez la composante connexe qui contient une cellule de départ dans une grille.
- [Climbing Stairs](/fr/algorithms/problems/climbing-stairs) : comptez les façons distinctes d'atteindre le sommet quand chaque mouvement monte une ou deux marches.
- [Maximum Subarray](/fr/algorithms/problems/maximum-subarray) : trouvez la plus grande somme d'un sous-tableau contigu non vide.
