Explorez les sommets connectés avec une file ou une pile en évitant le travail en double.

## Quand l'utiliser

- Trouver des composantes connexes.
- Explorer des grilles.
- Déterminer l'accessibilité.

## Étapes

1. Choisissez un sommet de départ.
2. Marquez les sommets pour ne pas les revisiter.
3. Ajoutez chaque voisin non visité à la frontière.

## Complexité

| Mesure | Coût typique |
| --- | --- |
| Temps | `O(sommets + arêtes)` |
| Espace | `O(sommets)` |

## Exemples de problèmes

- [Flood Fill](/fr/algorithms/problems/flood-fill) : recolorez la composante connexe qui contient une cellule de départ dans une grille.
