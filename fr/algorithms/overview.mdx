Le catalogue d'algorithmes rassemble 10 problèmes de code courants et 10 motifs algorithmiques réutilisables. Chaque solution est une implémentation TypeScript couverte par des tests automatisés : le code de chaque page est donc exactement celui qui passe ces tests.

Utilisez le catalogue pour étudier une technique, préparer des entretiens techniques ou trouver une implémentation de référence pour un problème connu.

La complexité utilise la notation grand O. Par exemple, `O(n)` signifie que le coût croît linéairement avec la taille d'entrée `n`. Pour apprendre à lire ces valeurs, consultez [Analyse de complexité](/fr/algorithms/patterns/complexity-analysis).
