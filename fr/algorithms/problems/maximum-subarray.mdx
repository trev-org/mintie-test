Trouvez la plus grande somme d'un sous-tableau contigu non vide.

| Propriété | Valeur |
| --- | --- |
| Numéro du problème | 53 |
| Difficulté | Moyen |
| Complexité temporelle | `O(n)` |
| Complexité spatiale | `O(1)` |
| Problème original | [LeetCode](https://leetcode.com/problems/maximum-subarray/) |

## Approche

1. Suivez la meilleure somme se terminant à la valeur courante.
2. Prolongez le sous-tableau précédent ou démarrez-en un nouveau à la valeur courante.
3. Conservez la plus grande somme rencontrée.

## Solution

```typescript solution.ts
export function maxSubArray(nums: readonly number[]): number {
  if (nums.length === 0) {
    throw new RangeError("nums must not be empty");
  }

  let bestEndingHere = nums[0]!;
  let bestOverall = nums[0]!;
  for (let index = 1; index < nums.length; index += 1) {
    const value = nums[index]!;
    bestEndingHere = Math.max(value, bestEndingHere + value);
    bestOverall = Math.max(bestOverall, bestEndingHere);
  }
  return bestOverall;
}
```

## Exemple

```typescript Example
maxSubArray([-2,1,-3,4,-1,2,1,-5,4])
// => 6
```

Le sous-tableau contigu [4, -1, 2, 1] a la plus grande somme.

## Cas limites

- Une entrée entièrement négative renvoie sa plus grande valeur.
- Une entrée à une seule valeur renvoie cette valeur.
- L'implémentation rejette un tableau vide, car le sous-tableau doit être non vide.
