Trouvez la somme maximale de tout sous-tableau contigu non vide.

<Note>
  Cette page propose un résumé original et renvoie au
  [problème source](https://leetcode.com/problems/maximum-subarray/). L’implémentation est testée dans le
  [dépôt de code](https://github.com/trev-org/mintie-test-code/blob/main/algorithms/problems/0053-maximum-subarray/solution.ts).
</Note>

## Algorithme

<Steps>
  <Step title="Étape 1">
    Suivez la meilleure somme se terminant à la valeur courante.
  </Step>
  <Step title="Étape 2">
    Prolongez le sous-tableau précédent ou commencez-en un nouveau à la valeur courante.
  </Step>
  <Step title="Étape 3">
    Conservez la plus grande somme rencontrée.
  </Step>
</Steps>

## Implémentation

```typescript
export function maxSubArray(nums: readonly number[]): number {
  if (nums.length === 0) {
    throw new RangeError("nums must not be empty");
  }

  let bestEndingHere = nums[0]!;
  let bestOverall = nums[0]!;
  for (let index = 1; index < nums.length; index += 1) {
    const value = nums[index]!;
    bestEndingHere = Math.max(value, bestEndingHere + value);
    bestOverall = Math.max(bestOverall, bestEndingHere);
  }
  return bestOverall;
}
```

## Complexité

| Mesure | Complexité |
| --- | --- |
| Temps | `O(n)` |
| Espace auxiliaire | `O(1)` |

## Exemple d’utilisation

```typescript
const result = maxSubArray([-2,1,-3,4,-1,2,1,-5,4]);
console.log(result);
```

**Sortie :** `6`

Le sous-tableau contigu [4, -1, 2, 1] possède la somme maximale.

## Cas limites

- Lorsque toutes les valeurs sont négatives, la plus grande valeur individuelle est renvoyée.
- Une entrée contenant une seule valeur renvoie cette valeur.
- L’implémentation rejette un tableau vide, car le sous-tableau doit être non vide.
