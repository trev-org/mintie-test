Find the largest sum of any non-empty contiguous subarray.

<Note>
  This page uses an original summary and links to the
  [source problem](https://leetcode.com/problems/maximum-subarray/). The implementation is tested in the
  [code repository](https://github.com/trev-org/mintie-test-code/blob/main/algorithms/problems/0053-maximum-subarray/solution.ts).
</Note>

## Algorithm

<Steps>
  <Step title="Step 1">
    Track the best sum ending at the current value.
  </Step>
  <Step title="Step 2">
    Either extend the previous subarray or start a new one at the current value.
  </Step>
  <Step title="Step 3">
    Keep the largest sum seen anywhere.
  </Step>
</Steps>

## Implementation

```typescript
export function maxSubArray(nums: readonly number[]): number {
  if (nums.length === 0) {
    throw new RangeError("nums must not be empty");
  }

  let bestEndingHere = nums[0]!;
  let bestOverall = nums[0]!;
  for (let index = 1; index < nums.length; index += 1) {
    const value = nums[index]!;
    bestEndingHere = Math.max(value, bestEndingHere + value);
    bestOverall = Math.max(bestOverall, bestEndingHere);
  }
  return bestOverall;
}
```

## Complexity

| Measure | Complexity |
| --- | --- |
| Time | `O(n)` |
| Auxiliary space | `O(1)` |

## Example usage

```typescript
const result = maxSubArray([-2,1,-3,4,-1,2,1,-5,4]);
console.log(result);
```

**Output:** `6`

The contiguous subarray [4, -1, 2, 1] has the largest sum.

## Edge cases

- An all-negative input returns its largest single value.
- A one-value input returns that value.
- The implementation rejects an empty array because the subarray must be non-empty.
