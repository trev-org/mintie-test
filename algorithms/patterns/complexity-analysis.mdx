Describe how runtime and auxiliary memory grow as input size increases.

## When to use

- Compare valid approaches.
- Explain scalability.
- Document tradeoffs.

## Steps

1. Identify the input size.
2. Count dominant operations.
3. Drop constants and lower-order terms.

## Example problems

- [Two Sum](/algorithms/problems/two-sum): Return the indexes of two numbers whose sum equals the target.
- [Valid Parentheses](/algorithms/problems/valid-parentheses): Determine whether every opening bracket is closed in the correct order.
- [Valid Palindrome](/algorithms/problems/valid-palindrome): Check whether the alphanumeric characters read the same forward and backward, ignoring case.
- [Binary Search](/algorithms/problems/binary-search): Find a target value in a sorted array and return its index.
- [Merge Two Sorted Lists](/algorithms/problems/merge-two-sorted-lists): Merge two sorted linked lists into one sorted list by reusing their nodes.
- [Best Time to Buy and Sell Stock](/algorithms/problems/best-time-to-buy-and-sell-stock): Find the largest profit from one purchase followed by one later sale.
- [Invert Binary Tree](/algorithms/problems/invert-binary-tree): Mirror a binary tree by swapping every node's left and right children.
- [Flood Fill](/algorithms/problems/flood-fill): Recolor the connected component containing a starting cell in a grid.
- [Climbing Stairs](/algorithms/problems/climbing-stairs): Count the distinct ways to reach the top when each move climbs one or two steps.
- [Maximum Subarray](/algorithms/problems/maximum-subarray): Find the largest sum of any non-empty contiguous subarray.
