Repeatedly discard half of an ordered search space.

## When to use

- Search sorted data.
- Find a monotonic boundary.
- Reduce linear search to logarithmic time.

## Steps

1. Define inclusive or exclusive bounds.
2. Evaluate the midpoint.
3. Discard the impossible half.

## Complexity

| Measure | Typical cost |
| --- | --- |
| Time | `O(log n)` |
| Space | `O(1)` |
