Maintain the best local state needed to make each next decision.

## When to use

- A local choice cannot hurt future choices.
- Only a running optimum is needed.
- The input can be processed once.

## Steps

1. Define the invariant carried forward.
2. Update it from the current value.
3. Record the best complete answer.

## Complexity

| Measure | Typical cost |
| --- | --- |
| Time | `O(n)` |
| Space | `O(1)` |
