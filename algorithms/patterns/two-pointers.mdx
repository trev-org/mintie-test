Move two indexes through a sequence while maintaining a useful relationship.

## When to use

- Compare values from both ends.
- Merge sorted sequences.
- Avoid a nested scan.

## Steps

1. Initialize pointers at meaningful boundaries.
2. Move the pointer that cannot remain.
3. Stop when the search region is exhausted.

## Complexity

| Measure | Typical cost |
| --- | --- |
| Time | `O(n)` |
| Space | `O(1)` |

- [Valid Palindrome](/algorithms/problems/valid-palindrome): Check whether the alphanumeric characters read the same forward and backward, ignoring case.
