Process nested or most-recent state in last-in, first-out order.

## When to use

- Validate nested delimiters.
- Simulate recursion.
- Track unresolved prior items.

## Steps

1. Push unresolved state.
2. Inspect or pop the latest state.
3. Validate the final stack.

## Complexity

| Measure | Typical cost |
| --- | --- |
| Time | `O(n)` |
| Space | `O(n)` |
