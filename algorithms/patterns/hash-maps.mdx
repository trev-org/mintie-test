Store values by key for expected constant-time membership and lookup.

## When to use

- Track values already seen.
- Count frequencies.
- Find a complement or duplicate.

## Steps

1. Choose a stable key.
2. Read before writing when order matters.
3. Store only the state needed later.

## Complexity

| Measure | Typical cost |
| --- | --- |
| Time | `O(n)` expected |
| Space | `O(n)` |
