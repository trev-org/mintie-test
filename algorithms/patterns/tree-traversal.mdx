Visit every node through recursive or iterative depth-first or breadth-first traversal.

## When to use

- Transform a tree.
- Aggregate subtree results.
- Search hierarchical data.

## Steps

1. Define the empty-tree base case.
2. Process the current node.
3. Traverse the child subtrees.

## Complexity

| Measure | Typical cost |
| --- | --- |
| Time | `O(n)` |
| Space | `O(h)` |
