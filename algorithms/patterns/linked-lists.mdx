Traverse and reconnect nodes without moving the values they contain.

## When to use

- Insert or remove through references.
- Merge node chains.
- Use constant auxiliary space.

## Steps

1. Keep references to current nodes.
2. Reconnect one link at a time.
3. Preserve the next node before overwriting a link.

## Complexity

| Measure | Typical cost |
| --- | --- |
| Time | `O(n)` |
| Space | `O(1)` |
