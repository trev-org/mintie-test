Describe how runtime and auxiliary memory grow as input size increases.

## When to use it

- Compare valid approaches.
- Explain scalability.
- Document tradeoffs.

## Algorithm

<Steps>
  <Step title="Step 1">
    Identify the input size.
  </Step>
  <Step title="Step 2">
    Count dominant operations.
  </Step>
  <Step title="Step 3">
    Drop constants and lower-order terms.
  </Step>
</Steps>
