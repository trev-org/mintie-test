Visit every node through recursive or iterative depth-first or breadth-first traversal.

## When to use it

- Transform a tree.
- Aggregate subtree results.
- Search hierarchical data.

## Algorithm

<Steps>
  <Step title="Step 1">
    Define the empty-tree base case.
  </Step>
  <Step title="Step 2">
    Process the current node.
  </Step>
  <Step title="Step 3">
    Traverse the child subtrees.
  </Step>
</Steps>

## Typical complexity

| Measure | Complexity |
| --- | --- |
| Time | `O(n)` |
| Auxiliary space | `O(h)` |

<Note>
  Exact complexity depends on the implementation and input. Each linked problem
  gives the bound for its tested solution.
</Note>
