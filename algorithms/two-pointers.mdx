Move two indexes through a sequence while maintaining a useful relationship.

## When to use it

- Compare values from both ends.
- Merge sorted sequences.
- Avoid a nested scan.

## Algorithm

<Steps>
  <Step title="Step 1">
    Initialize pointers at meaningful boundaries.
  </Step>
  <Step title="Step 2">
    Move the pointer that cannot remain.
  </Step>
  <Step title="Step 3">
    Stop when the search region is exhausted.
  </Step>
</Steps>

## Typical complexity

| Measure | Complexity |
| --- | --- |
| Time | `O(n)` |
| Auxiliary space | `O(1)` |

<Note>
  Exact complexity depends on the implementation and input. Each linked problem
  gives the bound for its tested solution.
</Note>
